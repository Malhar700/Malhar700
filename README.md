*Production-ready multi-stage optical inspection pipeline for automated Printed Circuit Board defect diagnosis.*

[![Python](https://img.shields.io/badge/Python-3.10+-blue?style=flat-square&logo=python)](https://github.com/Malhar700/pcb-defect-detector)

<p align="left">
  • <b>Multi-Stage Parallel Inference:</b> Utilizes an asynchronous ThreadPoolExecutor to run manufacturing trace inspection and physical damage detection concurrently.<br/>
  • <b>Optical Quality Check:</b> Rejects blurry images using Laplacian variance ($Var(\nabla^2 I) \ge 50.0$) and evaluates exposure boundaries ($20 \le \mu \le 240$) before inference.<br/>
  • <b>Hardware Accelerated:</b> Native Apple Silicon (MPS) and CUDA acceleration with FP16 half-precision for sub-100ms inference.<br/>
  • <b>Dual Interfaces:</b> "Gold + Obsidian" React web UI and native PySide6 desktop application for factory floor inspection.

## ⚙️ Engineering Principles

1. **Architecture Before Implementation:** Design clear interfaces, contracts, and failure boundaries before writing code.
2. **Security by Design:** Enforce strict input validation, rate limiting, and sandbox isolation on all file and network paths.
3. **Hardware-Aware Performance:** Maximize system hardware capabilities (e.g. FP16 tensor acceleration, asynchronous worker pools, streaming buffers).
4. **Clean & Reproducible:** Maintain clear READMEs, deterministic dependencies, and self-documenting codebases.
